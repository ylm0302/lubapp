# 标准分镜要素模板（基于《电影艺术词典》+知乎干货文）

> 参考：https://zhuanlan.zhihu.com/p/438800907
> 标准分镜八大要素：镜号 / 景别 / 角度 / 运动 / 画面 / 台词 / 声音 / 时长

---

## 一、标准分镜要素对照表

| 要素 | 说明 | 对应提示词模块 |
|------|------|---------------|
| 镜号 | 镜头序号，组接顺序 | 分镜01-09 |
| **景别** | 远景/全景/中景/近景/特写（被摄主体在画面中的范围） | 【景别】 |
| **角度** | 视角：平视/仰角/俯角/正面/侧面/背面 | 【角度】 |
| **运动** | 推/拉/摇/移/跟/升/降/旋转/晃动 | 【镜头】+【镜头运动补充】 |
| 画面 | 简明清晰描述画面内容 | 【画面】 |
| 台词 | 人物话语 | 【对白】 |
| **声音** | 人声+音乐+音响（环境音/音效/配乐） | 【声音设计】 |
| 时长 | 镜头时间长度 | 生成时长15秒 |

---

## 二、景别定义（截取成年人身体部位为标准）

| 景别 | 画面范围 |
|------|----------|
| 大远景 | 人物极小，环境占绝对主体 |
| 远景 | 人物全身+大部分环境 |
| 全景 | 人物全身，头顶留空、脚底留空 |
| 中景 | 人物膝盖以上 |
| 中近景 | 人物腰部以上 |
| 近景 | 人物胸部以上 |
| 特写 | 人物肩部以上/局部（手、眼、物体） |
| 大特写 | 局部细节放大（瞳孔、尘纹、枪尖） |

---

## 三、角度定义

| 角度 | 说明 | 表达含义 |
|------|------|----------|
| 平视 | 镜头与被摄主体视线同高 | 客观、平等、中性 |
| 仰角 | 镜头低于主体视线向上摄 | 增强主体气势、压迫感、崇高感 |
| 俯角 | 镜头高于主体向下摄 | 呈现布局、渺小感、掌控感 |
| 正面 | 镜头正对主体 | 直接对峙、情绪直给 |
| 侧面 | 镜头在主体侧方 | 展现轮廓、动作过程 |
| 背面 | 镜头在主体身后 | 悬念、留白、引导观众视线 |
| 斜侧面 | 镜头在主体斜侧方 | 立体感、空间纵深 |

---

## 四、镜头运动体系

| 运动 | 英文 | 说明 |
|------|------|------|
| 推 | Push-in | 镜头向主体推进，景别收紧 |
| 拉 | Pull-back | 镜头远离主体，景别放宽 |
| 摇 | Pan/Tilt | 镜头位置不动，水平/垂直旋转 |
| 移 | Track | 镜头沿地面平行移动 |
| 跟 | Follow | 镜头跟随主体移动 |
| 升 | Crane-up | 镜头升高 |
| 降 | Crane-down | 镜头降低 |
| 旋转 | Orbit/Roll | 镜头围绕主体旋转/自身滚动 |
| 晃动 | Handheld | 手持晃动，增强临场感 |

---

## 五、声音设计要素

| 类型 | 说明 | 案例 |
|------|------|------|
| 人声 | 对白、旁白、内心独白 | 角色台词 |
| 环境音 | 场景本底声音（持续） | 夜风、虫鸣、犬吠、路灯滋滋声 |
| 音效 | 动作/事件声音（瞬时） | 利爪破空、枪出如龙、光效迸发 |
| 配乐 | 背景音乐（烘托情绪） | 悬疑弦乐、燃向战歌、温情钢琴 |
| 音响 | 特殊效果声 | 空间扭曲声、低频嗡鸣 |

## 六、对白音色统一表（全剧固定）

| 角色 | 音色 | 音质 | 语速 | 语气 | 配音参数 |
|------|------|------|------|------|----------|
| 旁白 | 低沉男声 | 中低音略带沙哑 | 中速偏慢、字间留白 | 叙事神秘沧桑 | 48kHz/16bit/-3dB/街道混响 |
| 宋望 | 中低音男声 | 年轻有力量 | 中速干脆 | 冷漠自信、遇敌压低 | 同上 |
| 林冲 | 低沉威严男声 | 中年武将中音偏厚 | 偏慢字字铿锵 | 稳重正气威压 | 同上 |
| 路人 | 高音男声 | 紧张发颤 | 快速急促 | 惊恐求救 | 同上 |
| 苏晴 | 清亮温柔女声 | 中音偏甜年轻 | 中速柔和 | 坚定温柔 | 同上 |

## 七、光线统一体系（全剧固定）

- 三光源：暖黄路灯（主光3200K）+ 冷蓝月光（辅光6500K）+ 轮廓光
- 战斗附加：尘纹红光/召唤红光（第四光源）
- 结尾附加：裂缝暗紫光 / 光门蓝紫光
- 散射：水洼反射、丁达尔光柱、指缝透光、粒子球面散射

---

## 八、风格统一（全剧固定）

- 动态漫电影级，高对比低饱和，暗冷主调
- 红色系仅用于尘纹/召唤特效，局部高饱和
- 轻微胶片颗粒，主体锐利背景柔和
- 色彩曲线：暖黄→冷蓝→炽红→暗紫→蓝紫（情绪推进）
