## 一、场景转换与周边环境（统一规范）

第1集所有分镜发生在同一连续场景——**浮江市深夜老街**，无场景切换。周边环境各镜补充如下：

| 要素 | 详细说明 |
|------|----------|
| 时间 | 深夜约23:00-0:00，夜深人静 |
| 街道 | 单车道老街，石板路面湿润泛光（雨后/晨露） |
| 店铺 | 路边老式店铺全部卷帘门关闭，少数招牌灯箱亮着（暖白/淡红） |
| 路灯 | 间隔约15米一盏，暖黄色钠灯，光圈呈椭圆投射地面 |
| 树木 | 零星行道树（法国梧桐），枝叶在路灯下投出斑驳树影 |
| 群众 | **无**——深夜老街无人，只有宋望、路人与恶灵；片尾追加苏晴 |
| 车辆 | 偶尔有一辆出租车从远处街道驶过，车灯扫过（仅分镜01） |
| 声音 | 远处犬吠、虫鸣、路灯电流滋滋声、风声掠过巷口 |
| 天气 | 微阴，云层遮蔽部分月光，空气湿润有薄雾，地面水洼反射灯光 |

**转换方式：** 镜头之间全部用**硬切（Cut）**过渡，无淡入淡出（保持节奏），但每镜的"镜头过渡"段落已写明人物位置衔接。

## 二、镜头运动系统（统一规范）

### 镜头运动类型

| 类型 | 代码 | 说明 |
|------|------|------|
| 推镜 | Push-in | 镜头从远处向主体匀速推进，压缩空间感 |
| 拉镜 | Pull-back | 镜头从主体匀速拉远，扩张空间感 |
| 仰拍 | Low-angle | 镜头低于主体视线，向上仰摄，增强压迫感/气势 |
| 俯拍 | High-angle | 镜头高于主体，向下俯摄，呈现方位/布局 |
| 环拍 | Orbit | 镜头围绕主体弧形运动，展现立体感 |
| 横摇 | Pan | 镜头在水平方向旋转，跟随主体或展示环境 |
| 纵摇 | Tilt | 镜头在垂直方向升降，从头顶到脚底或反之 |
| 跟拍 | Follow | 镜头跟随主体平行移动，保持相对距离 |
| 升降 | Crane | 镜头垂直升降，配合推拉制造空间层次 |

### 各镜镜头运动补充

**分镜01**：远景推镜→中景→跟拍（侧前方45°）→停步后横摇45°跟随视线→推镜至面部近景
**分镜02**：中景→推镜至手部特写→上摇至面部→推镜至面部特写→定格
**分镜03**：全景→快速甩镜跟拍恶灵扑击→慢镜推近利爪→定格对峙
**分镜04**：侧面跟拍宋望入场→快切特写扣腕→仰拍宋望（低机位，增强压迫感）→环拍45°展现对峙空间
**分镜05**：中景→推镜至握拳特写→快速仰拍上摇至林冲全身→拉开至全景（双人同框）
**分镜06**：侧面全景→跟拍林冲刺击→慢动作枪刺特写→下拉至脚底→上摇回林冲站姿→定格
**分镜07**：中景→推镜至光点特写→上摇至宋望面部→缓推至面部特写
**分镜08**：近景→拉镜至中景→横摇270°跟随宋望转身→推镜至裂缝特写→拉镜至远景（宋望背影渺小）
**分镜09**：中景→侧后方跟拍两人行走→推镜至光门→俯拍两人背影与光门（高低机位切换）→定格

## 三、光线系统（统一规范）

### 三光源布光体系

每个分镜统一使用**三光源布光法**：

| 光源 | 位置 | 色温 | 强度 | 功能 |
|------|------|------|------|------|
| **主光（Key Light）** | 路灯（上方偏左/右） | 暖黄 3200K | 强 | 照明主体，塑造轮廓 |
| **辅光（Fill Light）** | 月光（正上方偏左） | 冷蓝 6500K | 中弱 | 补充暗部细节，冷色对比 |
| **轮廓光（Rim Light）** | 路灯/月光（主体后方） | 视情况 | 中 | 勾勒主体边缘，分离背景 |

### 光线变化规则

| 场景 | 光线变化 |
|------|----------|
| 正常行走（01-03镜） | 路灯固定暖黄，月光固定冷蓝，光线稳定，人物在路灯光圈间明暗交替 |
| 战斗状态（04-06镜） | 路灯开始闪烁（战斗能量干扰），尘纹红光/召唤红光加入光线系统，三光源变为四光源 |
| 事件结束（07-08镜） | 路灯恢复稳定，红色光粒子逐渐消散，回归暖黄+冷蓝双光源，裂缝加入幽暗紫光 |
| 片尾（09镜） | 光门蓝紫光成为主光源（从暖黄过渡到蓝紫），路灯退为辅助 |

### 光线散射与折射

- 路灯暖光通过**地面水洼**产生反射，形成倒影中的第二光源
- 月光穿过**薄雾/云层**产生柔光散射效果，形成光柱效果
- 尘纹红光通过**手掌/手指缝隙**产生透射，手背发光、指缝透光
- 召唤光效通过**空气中的尘埃粒子**产生丁达尔效应（光柱/光羽）
- 金色光点（林冲回归）向四周**球面散射**，逐渐衰减

## 四、画面对比度与色彩（统一规范）

| 参数 | 值 | 说明 |
|------|-----|------|
| 整体色调 | 暗冷（暗蓝黑） | 高对比，低饱和度 |
| 主色调 | 暖黄（路灯）+ 冷蓝（月光） | 互补色对比 |
| 红色系 | 仅用于尘纹/召唤特效 | 高饱和，局部点缀 |
| 对比度 | 高 | 亮部（路灯）→暗部（阴影）跨度大 |
| 暗部细节 | 保留 | 阴影中可见景物轮廓，不死黑 |
| 画面颗粒 | 轻微胶片颗粒 | 增加电影质感 |
| 锐度 | 中高 | 主体锐利，背景柔和 |

## 五、对白音色规范（统一标准）

### 角色音色表

| 角色 | 音色 | 语速 | 语气特征 | 适用分镜 |
|------|------|------|----------|----------|
| **旁白** | 低沉男声，中低音，略带沙哑，说书人风格 | 中速偏慢，每字之间留白 | 叙事感，神秘，略带沧桑 | 01、09 |
| **宋望** | 中低音男声，年轻有力量，沉稳霸气 | 中速，干脆利落，不拖泥带水 | 冷漠、自信、遇敌时压低声音更显威胁 | 02、04、05、07、08 |
| **林冲** | 低沉威严男声，中年武将，中音偏厚 | 偏慢，字字铿锵，有节奏感 | 稳重、正气、自带威压 | 06、07 |
| **路人** | 男声，较高音调，紧张 | 快速，急促，断断续续 | 惊恐、求救、慌乱 | 03 |
| **苏晴** | 清亮温柔女声，年轻，中音偏甜 | 中速，柔和 | 坚定、温柔（仅分镜09登场） | 09 |

### 配音参数

| 参数 | 值 |
|------|-----|
| 语言 | 普通话（中文） |
| 采样率 | 48kHz，16bit |
| 语气重音 | 按角色表标注 |
| 音量 | 统一 -3dB（避免爆音） |
| 环境混响 | 街道环境：轻微混响（模拟空旷街道） |
| 对白同步 | 各镜对白时长需与视频画面口型/动作同步 |

## 六、补充清单（未写明的通用规则）

1. 所有镜头中宋望的**右手手背尘纹**始终保持在可见位置（不遮挡）
2. 林冲的**红缨枪**在战斗时始终在画面中完整可见
3. 恶灵的**黑雾**效果不遮挡核心动作
4. 路灯**光圈边缘**作为人物站位参考线（构图三分法）
5. 地面**水洼倒影**始终包含在画面下半部分（增加空间层次）
6. 色彩传递：暖黄→冷蓝→炽红→暗紫→蓝紫，遵循故事情绪曲线
